Carpenter Connect · Mobile platform

A loyalty program built for India's skilled carpenters.

Carpenter Connect is a purpose-built digital loyalty program for India's skilled carpenters. It connects carpenters directly with top hardware brands, helping them earn, grow and stay engaged, all through a single mobile-first platform.

Overview

We designed and built the complete product: a progressive web app and Android app for carpenters, and an admin dashboard for the brand team to manage users, referrals and reward points.

The platform is live in Maharashtra and Jharkhand, and is now expanding to Karnataka and other states across India.
